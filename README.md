# PS-Sezhao（PS 去色罩）

PS-Sezhao 是一个面向**彩色负片扫描和相机翻拍**的 Photoshop UXP 插件。插件在本地估算橙色胶片基底，在光密度空间中转正，并生成新的正片像素图层。

> 照片不会上传到服务器，原负片图层不会被修改。

## 功能

- 自动从画面边框估算彩色负片基底色罩
- 支持框选未曝光胶片边缘后手动采样
- 在相对光密度空间进行负片转正
- 自动计算三通道黑点和白点
- 通用 C-41、Portra、Gold、Fujifilm、ECN-2 起始风格
- 曝光、对比度、中间调、饱和度和冷暖调整
- 8/16/32 位输入按原图位深处理
- 分块读写，降低高像素图的内存峰值
- 保存和复用“本卷参数”
- 输出到新图层，保持非破坏式工作流
- 面板内容独立滚动，生成状态始终可见
- Photoshop像素与选区读取统一使用模态作用域

## 安装

下载 GitHub Release 中的 `PS-Sezhao-v0.1.2.ccx`，双击后由 Adobe Creative Cloud Desktop 安装。安装后完全退出并重新打开 Photoshop，然后进入：

`插件（Plugins） → 胶片去色罩`

详细步骤见 [INSTALL.md](INSTALL.md)。

## 基本使用

1. 在 Photoshop 中打开扫描 TIFF/JPEG，或通过 Camera Raw 打开翻拍 RAW。
2. 选择负片所在的像素图层。
3. 点击“自动分析边框”。
4. 没有干净边框时，框选一块未曝光的橙色胶片，再点击“从当前选区采样”。
5. 底部显示“已完成基底分析，可以生成正片”后，选择胶片起始配置并调整参数。
6. 点击“生成正片图层”。
7. 同一卷胶片可保存并复用本卷参数。

## 输入建议

- 优先使用 16 位 TIFF，或由 Camera Raw 打开的 16 位文档。
- 翻拍 RAW 建议关闭自动色调、强锐化和强降噪，保留高光余量。
- 不要让红、绿、蓝通道在拍摄或扫描时发生严重剪切。
- 同一卷尽量保持相同灯板、相机白平衡和曝光设置。

## 当前限制

- 胶片配置是实用型起始风格，不是针对具体相机、灯板和乳剂组合制作的实验室光谱标定文件。
- 尚未提供空白灯板平场校正、镜头暗角校正和批量文件队列。
- 纯 JavaScript UXP 版本处理超高像素图片时会比后续 C++ 混合插件慢。
- 主要目标是彩色负片；黑白负片、正片和严重褪色胶片尚未单独优化。

## 技术说明

插件使用 Photoshop UXP Imaging API 直接读取和写入像素。基底估算后，单通道计算近似为：

```text
D = max(0, ln(Base / Pixel))
Positive = ToneMap(D)
```

随后应用胶片起始矩阵、对比度、曝光、饱和度和冷暖调整。全部运算在用户电脑上完成。
