# PS-Sezhao（PS 去色罩）

PS-Sezhao 是面向**彩色负片扫描和相机翻拍**的 Photoshop UXP 插件。它在本地估算橙色胶片基底，在光密度空间中转正，并提供画布实时预览与精细色彩校正。

> 照片不会上传到服务器。最终输出从原始负片图层重新计算，不会把低分辨率预览写进成品。

## 最新版本：v0.2.0

### 实时预览

- 参数变化后自动刷新 Photoshop 画布上的临时预览图层
- 800 / 1200 / 1800 px 三档预览精度
- 隐藏、显示、移除和手动刷新预览
- 最终以原始分辨率、原文档位深生成新图层

### 高级校色

- 色温 -300～+300
- 绿—洋红色调 -200～+200
- RGB 独立输出增益 0.25～3.00
- 胶片基底 R/G/B 独立微调
- 起始风格强度 0～200%
- 黑点、白点、阴影、高光
- 从 Photoshop 当前选区自动校正中性色

### 基础能力

- 自动从边框估算彩色负片基底
- 从未曝光胶片选区手动采样色罩
- 光密度空间转正和三通道范围分析
- 通用 C-41、Portra、Gold、Fujifilm、ECN-2 起始风格
- 8/16/32 位完整输出、分块处理和 Alpha 保留
- 保存和复用整卷分析与校色参数

## 推荐工作流

1. 打开负片扫描 TIFF/JPEG，或通过 Camera Raw 打开翻拍 RAW。
2. 选中原始负片像素图层。
3. 点击“自动分析边框”；没有干净边框时，框选未曝光胶片后点击“从选区采样色罩”。
4. 插件自动生成临时预览图层。
5. 拖动色温、色调、RGB 增益等参数，画布会自动刷新。
6. 对白衬衫、灰卡等区域建立选区，可点击“从当前选区校正中性色”。
7. 满意后点击“生成最终正片图层”。

## 安装

从 GitHub Release 下载 `PS-Sezhao-v0.2.0.ccx`，双击后由 Adobe Creative Cloud Desktop 安装。安装或升级后完全退出并重新打开 Photoshop。

详细说明见 [INSTALL.md](INSTALL.md)。

## 输入建议

- 优先使用 16 位 TIFF，或 Camera Raw 打开的 16 位文档。
- 翻拍时关闭自动色调、强锐化和强降噪，保留三通道高光余量。
- 同一卷保持相同灯板、相机白平衡和曝光设置。
- 自动色罩分析最好保留一圈未曝光的橙色边框。

## 当前限制

- 实时预览使用低分辨率临时像素层，属于调色参考；最终输出会重新进行完整分辨率运算。
- 频繁实时刷新会在 Photoshop 历史记录中产生预览更新记录。
- 胶片配置属于实用起始风格，尚不是特定相机、灯板和乳剂组合的光谱标定配置。
- 空白灯板平场校正、暗角校正和批量队列将在后续版本开发。
