# PS-Sezhao（PS 去色罩）

PS-Sezhao 是一个面向**彩色负片扫描和相机翻拍**的 Photoshop UXP 插件。第一版在本地读取当前图层，估算橙色胶片基底，在光密度空间中转正，并生成新的正片像素图层。

> 照片不会上传到服务器。原负片图层不会被修改。

## 第一版功能

- 自动从画面边框估算彩色负片基底色罩
- 支持框选未曝光胶片边缘后手动采样
- 在相对光密度空间进行负片转正
- 自动计算三通道黑点和白点
- 通用 C-41、Portra、Gold、Fujifilm、ECN-2 起始风格
- 曝光、对比度、中间调、饱和度和冷暖调整
- 8/16/32 位输入按原图位深处理
- 分块读写，降低高像素图的内存峰值
- 保存和复用“本卷参数”
- 输出到新图层，保持非破坏式工作流

## 推荐安装方式

下载 GitHub Release 中的 `PS-Sezhao-v0.1.0.ccx`，双击后由 Adobe Creative Cloud Desktop 安装。这是普通用户最简单的方式。

安装后重启 Photoshop，在：

`插件（Plugins） → 胶片去色罩`

打开面板。

详细步骤见 [INSTALL.md](INSTALL.md)。

## 基本使用

1. 在 Photoshop 中打开扫描 TIFF/JPEG，或通过 Camera Raw 打开翻拍 RAW。
2. 选择负片所在的像素图层。
3. 尽量让画面四周保留一圈未曝光的橙色胶片边框。
4. 点击“自动分析边框”。
5. 选择胶片起始配置，进行基础调整。
6. 点击“生成正片图层”。
7. 同一卷胶片可点击“保存为本卷参数”，再对后续画面载入。

当胶片边框太少、被裁掉或包含黑色片夹时，可先用 Photoshop 选区框选一块干净的橙色边框，再点击“从当前选区采样”。

## 输入建议

- 优先使用 16 位 TIFF，或由 Camera Raw 打开的 16 位文档。
- 翻拍 RAW 建议关闭自动色调、强锐化和强降噪，保留高光余量。
- 不要让红、绿、蓝通道在拍摄或扫描时发生严重剪切。
- 同一卷尽量保持相同灯板、相机白平衡和曝光设置。

## 当前限制

- 第一版的胶片配置是实用型“起始风格”，不是针对具体相机、灯板和乳剂组合制作的实验室光谱标定文件。
- 尚未提供空白灯板平场校正、镜头暗角校正和批量文件队列。
- 纯 JavaScript UXP 版本处理超高像素图片时会比后续 C++ 混合插件慢。
- 主要目标是彩色负片；黑白负片、正片和严重褪色胶片尚未单独优化。

## 技术说明

插件使用 Photoshop UXP Imaging API 直接读取和写入像素。基底估算后，单通道计算近似为：

```text
D = max(0, ln(Base / Pixel))
Positive = ToneMap(D)
```

随后应用胶片起始矩阵、对比度、曝光、饱和度和冷暖调整。全部运算在用户电脑上完成。
