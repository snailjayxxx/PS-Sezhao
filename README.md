# PS-Sezhao（PS 去色罩）

PS-Sezhao 是面向彩色负片扫描和相机翻拍的 Photoshop UXP 插件。它在本地估算胶片基底，在光密度空间中转正，并提供点击式吸管、大图预览和连续画布调色。

> 照片不会上传到服务器。最终输出从原始负片图层重新计算。

## 最新版本：v0.2.2

### 点击式吸管

- 点击胶片基底：启动后直接点击 Photoshop 画布或插件内大图预览
- 点击中性色：直接点击白色、灰色或其他应为中性的区域
- 取样范围：单点、3×3、5×5、11×11、21×21
- 自动更新胶片基底、密度范围或 RGB 输出增益

### 大图预览

- 1200 / 1800 / 2400 / 3200 px 四档精度
- 适应窗口、100%、200% 显示
- 预览区可扩展到 680 px 高
- 100% 和 200% 模式支持滚动查看细节
- 滑块变化后同步 Photoshop 画布与插件内大图

### 其他功能

- 自动边框分析和选区色罩采样
- 色温、色调、RGB 独立增益
- 黑点、白点、阴影、高光
- 胶片基底 R/G/B 微调
- 通用 C-41、Portra、Gold、Fujifilm、ECN-2 起始风格
- 8/16/32 位最终输出、分块处理和 Alpha 保留
- 保存和复用整卷参数

## 推荐流程

1. 打开负片并选中原始负片像素图层。
2. 使用“自动分析边框”，或点击“吸管：点击胶片基底”后直接点未曝光橙色边缘。
3. 在大图预览中选择适应窗口、100% 或 200%。
4. 拖动曝光、色温、色调和 RGB 增益，观察画布和大图同步变化。
5. 需要白平衡时，启动中性色吸管，点击白衬衫或灰色区域。
6. 满意后生成最终正片图层。

## 安装

从 GitHub Release 下载 `PS-Sezhao-v0.2.2.ccx`，双击后由 Adobe Creative Cloud Desktop 安装。最低支持 Photoshop 24.0。

详细说明见 [INSTALL.md](INSTALL.md)。
