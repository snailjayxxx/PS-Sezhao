PS-Sezhao v0.7.0-beta.5 安装说明

macOS Apple Silicon

  1. 打开 PS-Sezhao-Installer-macOS-arm64-v0.7.0-beta.5.dmg。
  2. 将 PS-Sezhao.app 拖到右侧 Applications 文件夹。
  3. 从 Finder 的“应用程序”中打开 PS-Sezhao。

拖动安装只复制 App。首次成功启动时，程序自动建立：

~/Library/Application Support/PS-Sezhao/
├── workspace.sqlite3
├── project/
├── lut/
└── logs/
    └── startup.log

数据库保持旧位置；project 用于项目归档和备份；lut 用于用户 Cube LUT；logs/startup.log 用于启动诊断。

未签名测试包仍会被 Gatekeeper 阻止。只有使用 Apple Developer ID 签名并完成 Apple 公证，才能避免首次手动确认。程序获准运行后若仍启动失败，会显示日志路径。

Windows 64 位

  1. 运行 PS-Sezhao-Installer-Windows-x64-v0.7.0-beta.5.exe。
  2. 默认安装到 %LOCALAPPDATA%\Programs\PS-Sezhao\。
  3. 安装器会创建开始菜单快捷方式，并可选择创建桌面快捷方式。

Windows 安装版在应用目录中保留 project、lut，首次启动时生成 logs。

启动与关闭

  • 普通启动不自动打开上次关闭时的照片。
  • 已有胶卷项目通过左侧“打开”手动恢复。
  • 关闭且当前有照片时，询问是否保存本次胶卷项目。
  • “是”保存后退出；“否”直接退出；“取消”返回程序。

便携版

PS-Sezhao/
├── PS-Sezhao.app 或 PS-Sezhao.exe
├── project/
├── lut/
├── logs/
├── 安装说明.html
└── .ps-sezhao-portable

用户 LUT

右侧“胶卷风格”区域提供“添加 LUT…”和“打开 LUT 文件夹”。支持标准 1D/3D .cube 文件。
