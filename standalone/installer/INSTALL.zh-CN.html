PS-Sezhao 独立版安装说明

安装版和便携版都使用同一套目录结构，程序、胶卷项目数据库和用户 LUT 放在同一个外层文件夹中：

PS-Sezhao/
├── PS-Sezhao.app 或 PS-Sezhao.exe
├── project/
│   └── workspace.sqlite3
├── lut/
├── 安装说明.html
└── .ps-sezhao-portable

macOS（Apple Silicon）

  1. 打开 PS-Sezhao-Installer-macOS-arm64-*.dmg。
  2. 双击“安装到用户应用程序.command”。安装器会复制到 ~/Applications/PS-Sezhao/。
  3. 安装完成后打开该文件夹，再打开 PS-Sezhao.app。
  4. 若 macOS 首次阻止未公证应用，请在 Finder 中按住 Control 点击 App，选择“打开”；也可进入“系统设置 → 隐私与安全性”确认打开。

不要只把 PS-Sezhao.app 单独拖到系统 /Applications。这样会失去同级的 project 和 lut 目录。安装脚本使用用户目录，不需要管理员权限。

Windows 64 位

  1. 运行 PS-Sezhao-Installer-Windows-x64-*.exe。
  2. 默认安装到 %LOCALAPPDATA%\Programs\PS-Sezhao\，无需管理员权限。
  3. 安装器会创建开始菜单快捷方式，并可选择创建桌面快捷方式。
  4. 更新安装会替换程序，但不会删除 project 和 lut 中的用户数据。

便携版

解压 ZIP 后保留整个 PS-Sezhao 文件夹，不要只移动其中的可执行文件。可把整个文件夹放在本机硬盘、移动硬盘或 NAS 的可写目录中。

胶卷项目迁移

Beta 3 第一次启动时，会把旧位置中的 workspace.sqlite3 自动复制到新的 project 文件夹。旧数据库不会删除，并会在新目录生成 MIGRATED_FROM.txt 记录来源。

  • 旧 macOS 位置：~/Library/Application Support/PS-Sezhao/workspace.sqlite3
  • 旧 Windows 位置：%LOCALAPPDATA%\PS-Sezhao\workspace.sqlite3

添加用户 LUT

  1. 在右侧“胶卷风格”区域点击“添加 LUT…”；当前支持标准 .cube，包括 1D 和 3D LUT。
  2. 程序验证后会把文件复制到同级 lut 文件夹。
  3. 用户 LUT 会出现在胶卷风格下拉列表中，使用“胶卷强度”控制混合比例。
  4. 也可以手动把 .cube 文件复制到 lut 文件夹，重新启动程序或再次打开风格列表即可读取。

项目只保存 LUT 文件名，不把 LUT 内容写进数据库。跨电脑迁移时需要同时复制 project 和 lut 文件夹。

卸载

Windows 可在系统“已安装的应用”中卸载；安装器会保留 project 和 lut。macOS 直接删除 ~/Applications/PS-Sezhao/PS-Sezhao.app 即可，保留同级数据目录。确定不再需要项目后，再手动删除整个 PS-Sezhao 文件夹。
