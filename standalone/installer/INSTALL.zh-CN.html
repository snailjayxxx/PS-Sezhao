PS-Sezhao v0.7.0-beta.4 安装说明

macOS Apple Silicon

  1. 打开 PS-Sezhao-Installer-macOS-arm64-v0.7.0-beta.4.dmg。
  2. 将 PS-Sezhao.app 拖到右侧 Applications 文件夹。
  3. 从 Finder 的“应用程序”中打开 PS-Sezhao。

Beta 4 不再运行 .command 安装脚本。标准安装版数据库保留在：

~/Library/Application Support/PS-Sezhao/workspace.sqlite3

用户 LUT 保存在：

~/Library/Application Support/PS-Sezhao/lut/

只有使用 Apple Developer ID 签名并完成 Apple 公证的构建，才能避免首次打开时的 Gatekeeper 手动确认。构建流程已经支持自动签名和公证，但发布者必须配置有效的 Apple 开发者证书和公证凭据。

Windows 64 位

  1. 运行 PS-Sezhao-Installer-Windows-x64-v0.7.0-beta.4.exe。
  2. 默认安装到 %LOCALAPPDATA%\Programs\PS-Sezhao\。
  3. 安装器会创建开始菜单快捷方式，并可选择创建桌面快捷方式。

Windows 安装版继续在应用目录中保留 project 和 lut。

启动与关闭

  • 普通启动时不再自动打开上次关闭时的照片。
  • 已有胶卷项目通过左侧“打开”手动恢复。
  • 关闭且当前有照片时，会询问是否保存本次胶卷项目。
  • “是”保存后退出；“否”直接退出并清空临时照片列表；“取消”返回程序。
  • 临时工作区选择保存时，需要输入胶卷项目名称。

便携版

便携 ZIP 必须保留整个外层文件夹：

PS-Sezhao/
├── PS-Sezhao.app 或 PS-Sezhao.exe
├── project/
│   └── workspace.sqlite3
├── lut/
├── 安装说明.html
└── .ps-sezhao-portable

用户 LUT

右侧“胶卷风格”区域提供“添加 LUT…”和“打开 LUT 文件夹”。支持标准 1D/3D .cube 文件。
