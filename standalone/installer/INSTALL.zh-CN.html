PS-Sezhao v0.7.2 安装说明

macOS Apple Silicon

  1. 删除“应用程序”中的旧版 PS-Sezhao.app。
  2. 打开 PS-Sezhao-Installer-macOS-arm64-v0.7.2.dmg。
  3. 将 PS-Sezhao.app 拖到右侧 Applications 文件夹。
  4. 弹出 DMG 后，从 Finder 的“应用程序”中打开 PS-Sezhao。

不要直接在 DMG、下载目录或压缩包预览窗口中运行 App。

程序数据保存在：

~/Library/Application Support/PS-Sezhao/
├── workspace.sqlite3
├── project/
├── lut/
└── logs/
    └── startup.log

替换或删除 App 不会删除数据库、项目和 LUT。

v0.7.2 修复：macOS 包已完全移除可能造成 PyEval_RestoreThread、SIGABRT 和 Abort trap: 6 的 TkDND 原生扩展。Finder 拖放暂时停用，请使用“添加图像”或“添加文件夹”。Windows 拖放不受影响。

当前未配置 Apple Developer ID 的发行包仍可能被 Gatekeeper 阻止。首次可在 Finder 中右键 App，选择“打开”。

Windows 64 位

  1. 运行 PS-Sezhao-Installer-Windows-x64-v0.7.2.exe。
  2. 默认安装到 %LOCALAPPDATA%\Programs\PS-Sezhao\。
  3. 安装器会创建开始菜单快捷方式，并可选择创建桌面快捷方式。

Windows 安装版在应用目录中保留 project、lut，首次启动时生成 logs。

裁切工具

  • 点击“裁切”进入完整画面编辑，按钮变为“完成裁切”。
  • 显示黄色裁切边框和八个控制点。
  • 可拖动角点、边框中点、框内区域，也可在框外重新画框。
  • 点击“完成裁切”应用范围；“重置裁切”恢复完整画面。

旋转与几何调整

  • 左右旋转会同步更新预览、裁切方向和导出方向。
  • 水平翻转、垂直翻转和拉直会立即更新当前照片。
  • 操作失败时显示具体错误，不再静默无反应。

风格选择

扫描仪与胶卷选择器直接使用右栏剩余宽度：

扫描仪风格  [完整宽度选择框 ▼]
胶卷风格    [完整宽度选择框 ▼]
  • 选择框紧跟在标签后面，不再缩在右侧一小块区域。
  • 候选列表直接嵌入右侧栏，在选择框下方展开。
  • 不会创建独立浮动窗口，因此不会跑到屏幕左上角。
  • 列表最多显示 12 行，更多项目使用滚动条。

启动与关闭

  • 普通启动不自动打开上次关闭时的照片。
  • 已有胶卷项目通过左侧“打开”手动恢复。
  • 关闭且当前有照片时，询问是否保存本次胶卷项目。
  • “是”保存后退出；“否”直接退出；“取消”返回程序。

便携版

PS-Sezhao/
├── PS-Sezhao.app 或 PS-Sezhao.exe
├── project/
├── lut/
├── logs/
├── 安装说明.html

用户 LUT

右侧“胶卷风格”区域提供“添加 LUT…”和“打开 LUT 文件夹”。支持标准 1D/3D .cube 文件。
